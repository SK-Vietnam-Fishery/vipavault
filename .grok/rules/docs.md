# docs layout

Canonical rule and catalog: `docs/INDEX.md`.
Project summary: `docs/README.md`.

- Docs root holds only `README.md`, `INDEX.md`, `vipavault-spec.md`, `technical-decisions.md`.
- New UX/brand drafts → `docs/design/`. Reviews / unapproved options → `docs/reviews/`. How-tos → `docs/guides/`. Numbered lessons → `docs/curriculum/`.
- Do not move `docs/vipavault-spec.md` or `docs/technical-decisions.md` without an explicit human request and a full link update.
- Spec wins over other files under `docs/`. Approved decisions go to spec, `technical-decisions.md`, or `.context/decisions/` — not left only in `reviews/`.
- Technical brainstorm stays in `.context/proposals/`, not `docs/`.
